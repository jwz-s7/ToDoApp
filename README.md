# ToDo DevOps

Estrutura inicial do projeto ToDo DevOps com Node.js 22 LTS, Express e CommonJS.

## Estrutura

- src/ para a aplicação
- tests/ para testes futuros
- .github/workflows/ para CI

## Como executar

1. Instale as dependências:
   npm install
2. Inicie o servidor:
   npm start
3. Acesse:
   http://localhost:3000/

A rota raiz retorna:

ToDo API funcionando.
